# Импорт геометрии и загрузка материалов { .gisogd-reference-title }

В системе используются разные способы загрузки пространственных данных. Перед выбором файла проверьте, что открыто: карта или вкладка «Загрузка материалов» в карточке документа. У этих операций различаются назначение, команды и форматы.

## Импорт геометрии на карте

Импорт используется для загрузки координат и отображения границ объектов на карте.

| Исходные данные | Порядок действий |
| --- | --- |
| Файл MIF, DXF или TAB | На панели карты выбрать **«Импорт → Файл»**, указать файл с координатами и систему координат, затем нажать **«Импортировать»** |
| Текст WKT | Выбрать **«Импорт → WKT»**, ввести тип геометрии и координаты в текстовой строке, выбрать систему координат |

После загрузки координат на карте отображается граница объекта. Подробное описание и снимки окон приведены в разделе [4.5.2.12 — Импорт геометрии](../operations/map.md#45212).

## Загрузка материалов в карточке документа

Во вкладке «Загрузка материалов» карточки документа территориального планирования муниципального образования расположен блок «Загрузка пространственных данных». Он предназначен для загрузки функциональных зон и объектов территориального планирования.

| Команда | Какие данные загружаются |
| --- | --- |
| «Загрузить функциональные зоны» | Архив с данными функциональных зон. Открывается окно «Импорт»; файл выбирается кнопкой «Выбрать». После обработки зоны добавляются в соответствующий реестр |
| «Загрузить контуры функциональных зон» | Геометрия контуров из ZIP-архива с векторными файлами GML в системе координат EPSG:3857 |
| «Загрузить объекты из ZIP-архива с векторными файлами» | Архив с векторными файлами GML |

Требование **EPSG:3857** в этом описании относится к команде **«Загрузить контуры функциональных зон»**. Оно не является общим требованием ко всем операциям импорта на карте.

**Кнопка «Удалить вектор» удаляет все ранее загруженные векторные данные текущего документа.** Не используйте её для удаления отдельного контура.

Порядок работы с вкладкой приведён в разделе [5.4.3.4 — Загрузка материалов](../gisogd/registries/section-3.md#5434).

## Что проверить перед загрузкой

1. Открыта нужная карта или карточка документа.
2. Формат исходных данных соответствует выбранной команде.
3. Для импорта на карте выбрана система координат исходных данных. Расшифровка сокращения [МСК](../introduction.md#term-msk) приведена в перечне терминов.

Если система координат исходного материала неизвестна, уточните её у поставщика данных или администратора перед импортом.
