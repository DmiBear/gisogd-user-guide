# Фильтры и статусы заявок { .gisogd-reference-title }

Фильтры журнала помогают отобрать записи для просмотра. Команда «Сменить статус» в карточке заявления изменяет статус выбранной заявки. Это разные действия: выбор условия в журнале не является изменением статуса заявки.

## Отбор по статусу в журнале

В журнале поступивших заявок для фильтрации по статусу просмотра используются значения:

- «Все»;
- «Новое»;
- «Зарегистрировано»;
- «В работе»;
- «Исполнено»;
- «Отказано».

**«Все» — условие отбора, а не статус отдельной заявки.** Оно не ограничивает выборку конкретным статусом.

Расположение фильтров показано в разделе [5.2 — Регистрация заявок](../gisogd/requests.md#52). Общий порядок применения фильтров описан в разделе [4.4 — Фильтрация записей](../operations/records.md#44).

## Отбор по отправителю

В фильтре по статусу отправителя доступны значения «Все», «Лично», «Почтовое отделение», «Электронная почта», «МФЦ», «ЕСМЭВ», «ПГУ», «Иные».

Значения «Лично», «Почтовое отделение», «Электронная почта» и другие в этом списке относятся к способу поступления заявки, а не к этапу её обработки. Для сокращений [МФЦ](../introduction.md#term-mfc) и [ПГУ](../introduction.md#term-pgu) доступны пояснения в перечне терминов.

## Изменение статуса в карточке заявления

В карточке заявления на выдачу разрешения на строительство кнопка **«Сменить статус»** открывает другой список:

- «Новое»;
- «Зарегистрировано»;
- «В работе»;
- «Черновик»;
- «Отправлено в ведомство»;
- «Услуга оказана»;
- «Отказ».

Порядок открытия карточки и выбор статуса показаны в разделе [5.2.1 — Выдача разрешения на строительство](../gisogd/requests.md#521).

Названия «Исполнено» и «Отказано» в фильтре журнала отличаются от «Услуга оказана» и «Отказ» в карточке. Перечни приведены отдельно; они не задают последовательность переходов и не устанавливают автоматическое соответствие между значениями.
