# Справочные сведения { .gisogd-reference-title }

В этом разделе собраны пояснения к обозначениям и операциям, которые встречаются в разных частях системы. Подробный порядок действий и снимки интерфейса остаются в соответствующих разделах руководства.

| Тема | Содержание |
| --- | --- |
| [Условные обозначения и кнопки](conventions.md) | Обязательные и недоступные для редактирования поля, выбор значений, связь и разрыв связи между записями |
| [Импорт геометрии и загрузка материалов](import.md) | Различия между инструментами карты и загрузкой пространственных данных в карточке документа |
| [Файлы и электронная подпись](files-and-signature.md) | Добавление файлов, предварительный просмотр, выгрузка файлов Word и сведения о подписи |
| [Фильтры и статусы заявок](application-statuses.md) | Условия отбора в журнале и изменение статуса в карточке заявления |
| [Термины и сокращения](../introduction.md#15) | Расшифровка 53 терминов и сокращений, используемых в руководстве |

В карточке дела о земельном участке можно перейти к описанию каждой из [14 вкладок](../gisogd/registries/section-13/index.md#case-tabs). Названия вкладок в этом перечне являются ссылками на соответствующие инструкции.
