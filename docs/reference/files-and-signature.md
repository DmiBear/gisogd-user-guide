# Файлы и электронная подпись { .gisogd-reference-title }

Файлы документа, предварительный просмотр и сведения об электронной подписи находятся в разных частях карточки. Ниже приведён порядок выбора нужной вкладки.

## Добавление и просмотр файлов

1. Открыть вкладку **«Приложенные файлы»** нужной карточки.
2. Нажать **«Выберите файлы»** и выбрать файлы на компьютере.
3. Выбрать добавленный файл в списке слева. Если предварительный просмотр предусмотрен для его формата, содержимое отобразится в области просмотра.

| Формат | Способ просмотра |
| --- | --- |
| PDF, JPG, PNG и другие форматы, поддерживаемые системой | Предварительный просмотр в окне документа |
| Word | Выгрузка файла и просмотр вне системы |

Отсутствие предварительного просмотра не следует считать подтверждением того, что файл не добавлен: проверьте список прикреплённых файлов. Для Word просмотр вне системы является предусмотренным способом работы.

Расположение списка файлов, области просмотра и кнопки загрузки показано в разделе [4.5.1 — Вкладка «Приложенные файлы»](../operations/records.md#451). Работа с файлами документа ГИСОГД описана в разделе [5.3.2 — Размещение документа во вкладке «Документы ГИСОГД»](../gisogd/document-placement.md#532).

## Сведения об электронной подписи

В карточке **«Документы ГИСОГД»** открыть вкладку **«Электронная подпись»**. В ней отображаются сведения об усиленной квалифицированной электронной подписи, которой подписан документ. Поля заполняются автоматически при загрузке подписанного файла.

В блоке **«Архив ЭП»** отображаются архивные записи об электронных подписях. Расшифровка [ЭП](../introduction.md#term-ep) приведена в перечне терминов.

Это описание относится к отображению сведений о подписи. Оно не заменяет инструкцию по подписанию файла или проверке действительности подписи.

Вкладка и блок архива показаны в разделе [5.3.2 — Размещение документа во вкладке «Документы ГИСОГД»](../gisogd/document-placement.md#document-signature).
