# 5.3 Размещение документа в ГИСОГД

Документы ГИСОГД хранятся в одноимённом реестре, который включает документы всех разделов и типов. Для каждого раздела Системы предусмотрен отдельный реестр со своим набором атрибутов. Внесение документа выполняется через карточку записи соответствующего реестра. Для открытия реестра нужного раздела выбрать соответствующий пункт меню (рисунок 53).

## 5.3.1 Создание записи в реестре раздела

Для всех разделов алгоритм действий по добавлению записи в реестр и внесению документа ГИСОГД в раздел одинаковый:

1. добавить в реестр новую запись, заполнив все необходимые поля в карточке. Сохранить данные;

2. во вкладке «Документы ГИСОГД» в карточке реестра добавить документ ГИСОГД, заполнив все необходимые поля и приложив файлы документа.

После сохранения документа ГИСОГД он появится в списке документов в карточке реестра соответствующего раздела (рисунок 54).

## 5.3.2 Размещение документа во вкладке «Документы ГИСОГД»

Карточка «Документы ГИСОГД» открывается при добавлении или редактировании документа в любом разделе системы. Она содержит следующие вкладки: «Основное», «Приложенные файлы», «Электронная подпись», «Связанные объекты». Вид карточки одинаков для всех разделов.

Во вкладке «Основное» расположены три информационных блока: «Основная информация», «Регистрация в ГИСОГД» и «Территория действия документа» (рисунок 55).

<figure class="doc-figure" markdown="span">
  ![Рисунок 55 — Раздел «Основное» в карточке «Документы ГИСОГД».](../assets/images/gisogd/figure-055.png)
  <figcaption>Рисунок 55 — Раздел «Основное» в карточке «Документы ГИСОГД».</figcaption>
</figure>

Блок «Основная информация» включает следующие поля:

- «Раздел» — выбрать из выпадающего списка раздел ГИСОГД, к которому относится документ;

- «Классификатор» — выбрать тип документа из справочника;

- «Категория» — указать категорию документа;

- «Наименование» — ввести наименование документа;

- «Номер» — указать номер документа;

- «Дата» — выбрать дату документа с помощью календаря;

- «Кем выдан» — выбрать организацию или орган власти, издавший документ;

- «Статус» — выбрать текущий статус документа;

- «Заявитель» — выбрать заявителя из справочников;

- «Окончание действия» — при необходимости указать дату окончания срока действия документа;

- «Web-адрес публикации» — ввести ссылку на публикацию документа в интернете, если она имеется.

В блоке «Регистрация в ГИСОГД» поля «Номер регистрации», «Дата регистрации» и «Сотрудник» заполняются автоматически при сохранении документа. Для связывания документа с заявкой на размещение в поле «Заявка на размещение» выбрать нужную заявку из выпадающего списка.

В блоке «Территория действия документа» указать территорию, на которую распространяется действие документа:

- «Муниципальные образования» — выбрать одно или несколько муниципальных образований из списка;

- «Поселение» — при необходимости выбрать поселение;

- «Населенный пункт» — при необходимости выбрать населенный пункт.

Регистрационный номер документа ГИСОГД формируется согласно требованиям приказа Минстроя от 6 августа 2020 г. № 433/пр и состоит из кода ОКТМО муниципалитета, номера раздела ГИСОГД, года внесения документа и порядкового номера документа в году.

Вкладка «Приложенные файлы» предназначена для загрузки файлов, прилагаемых к документу (рисунок 56).

Во вкладке «Электронная подпись» отображаются сведения об усиленной квалифицированной электронной подписи, которой подписан документ. Поля заполняются автоматически при загрузке подписанного файла (рисунок 57).

Во вкладке «Связанные объекты» устанавливаются связи документа с другими объектами системы:

- дела о земельных участках;

- проекты планировки территории;

- инженерные изыскания;

- программы реализации документов территориального планирования.

## 5.3.3 Связывание документа ГИСОГД с заявкой на размещение

Если в журнале заявок зарегистрирована заявка на размещение документа ГИСОГД, после создания записи в соответствующем разделе и добавления документа связать его с заявкой. Для этого после сохранения документа в карточке выбрать заявку по номеру и дате из выпадающего списка, затем сохранить карточку документа (рисунок 58).

После создания документа ГИСОГД в заявке на размещение доступен выбор созданного документа (рисунок 59).

Все связанные объекты добавляются в карточку «Документы ГИСОГД» на вкладку «Связанные объекты», описанную в разделе 5.4.7.3.
