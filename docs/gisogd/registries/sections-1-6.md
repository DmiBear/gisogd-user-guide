# 5.4 Реестры документов

Разделы ГИСОГД, перечисленные в разделе [5.1 «Разделы и документы ГИСОГД»](../overview.md#51), ведутся в отдельных реестрах. В каждом реестре создаются записи об объектах соответствующего вида, а к записям прикрепляются документы ГИСОГД. Поэтому заполнение сведений по разделам выполняется через карточки записей соответствующих реестров.

Выберите нужный реестр. Для каждого раздела открывается отдельная страница с полями карточки и рисунками.
