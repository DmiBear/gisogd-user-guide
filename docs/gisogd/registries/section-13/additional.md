# 5.4.13.10 Вкладка «Публичные сервитуты»

Вкладка «Публичные сервитуты» предназначена для учёта сведений о публичных сервитутах, установленных в отношении земельного участка. Добавление и редактирование сведений выполняются в карточке «Публичный сервитут» (рисунок 133).

<figure class="doc-figure" markdown="span">
  ![Рисунок 133 — Карточка «Публичный сервитут». Вкладка «Основное».](../../../assets/images/gisogd/figure-133.jpg)
  <figcaption>Рисунок 133 — Карточка «Публичный сервитут». Вкладка «Основное».</figcaption>
</figure>

Карточка содержит вкладки «Основное», «Документы ГИСОГД» и «Приложения».

Во вкладке «Основное» в блоке «Основная информация» указываются следующие данные:

1. «Вид сервитута» — выбрать вид публичного сервитута из выпадающего списка;

2. «Статус» — выбрать текущий статус публичного сервитута;

3. «Площадь, кв. м» — указать площадь территории публичного сервитута в квадратных метрах;

4. «Номер в ЕГРН» — ввести номер публичного сервитута в ЕГРН при наличии сведений;

5. «Земельный участок» — выбрать земельный участок, в отношении которого устанавливается публичный сервитут;

6. «Вид сервитута» — уточнить вид сервитута в соответствии со справочником системы;

7. «Заявитель» — выбрать заявителя из справочника. Для добавления записи нажать кнопку «+» справа от поля. Откроется окно «Реквизиты ЮЛ/ФЛ/ИП/ОИВ»;

8. «Назначение» — указать назначение устанавливаемого публичного сервитута;

9. «Форма собственности» — выбрать форму собственности из выпадающего списка;

10. «Срок установления» — указать срок, на который устанавливается публичный сервитут;

11. «Номер заявки» — ввести номер заявки на установление публичного сервитута;

12. «Дата заявки» — указать дату заявки с помощью календаря.

В блоке «Документ об утверждении» заполняются реквизиты документа, которым утверждено установление публичного сервитута:

1. «Кем утверждено» — выбрать орган или лицо, утвердившее документ. Для добавления записи нажать кнопку «+» справа от поля. Откроется окно «Реквизиты ЮЛ/ФЛ/ИП/ОИВ»;

2. «Чем утверждено» — выбрать документ или основание утверждения из справочника;

3. «Номер» — ввести номер утверждающего документа;

4. «Дата» — указать дату утверждающего документа;

5. «Актуальная дата» — указать дату актуальности сведений.

В правой части вкладки отображается карта. Инструменты карты предназначены для просмотра местоположения участка, изменения масштаба и проверки пространственного расположения публичного сервитута.

Блок «Адрес земельного участка» предназначен для указания местоположения участка. В поле «Муниципальное образование» выбрать муниципальное образование из списка, в поле «Адрес» выбрать адрес из справочника, при отсутствии адреса указать сведения в поле «Иное местоположение».

В блоке «Прочая информация» заполнить поле «Обоснование необходимости установления» и при необходимости указать дополнительные сведения в поле «Примечания».

Окно «Реквизиты ЮЛ/ФЛ/ИП/ОИВ» открывается при нажатии кнопки «+» у поля выбора физического лица, юридического лица, индивидуального предпринимателя или органа исполнительной власти (рисунок 134).

В окне «Реквизиты ЮЛ/ФЛ/ИП/ОИВ» заполнить поле «Наименование» и выбрать значение в поле «Тип». Для юридических лиц и индивидуальных предпринимателей доступен поиск по ЕГРЮЛ/ЕГРИП: ввести ИНН или наименование и нажать кнопку поиска. В поле «\[ФИАС\] Адрес регистрации / юридический адрес» выбрать адрес.

После выбора или заполнения реквизитов закрыть карточку и вернуться к карточке публичного сервитута. Выбранная запись будет подставлена в соответствующее поле.

Во вкладке «Документы ГИСОГД» отображается перечень документов ГИСОГД, связанных с публичным сервитутом (рисунок 135).

<figure class="doc-figure" markdown="span">

  <figcaption>Рисунок 135 — Вкладка «Документы ГИСОГД» в карточке «Публичный сервитут».</figcaption>

Сведения представлены в табличной форме с колонками «Муниципальные образования», «Дата документа ГИСОГД», «Регистрационный № ГИСОГД», «Раздел ГИСОГД», «Классификатор документов ГИСОГД». Для поиска использовать поле «Поиск», для настройки отображения использовать панели «Столбцы» и «Фильтры». Кнопки панели инструментов обеспечивают обновление списка, добавление, изменение и удаление связи с документом ГИСОГД. Порядок добавления и связывания документов ГИСОГД описан в пунктах 5.3.2 и 5.3.3 настоящего Руководства.

Во вкладке «Приложения» загружаются файлы, относящиеся к публичному сервитуту и не зарегистрированные как самостоятельные документы ГИСОГД (рисунок 136).

<figure class="doc-figure" markdown="span">
  ![Рисунок 136 — Вкладка «Приложения» в карточке «Публичный сервитут».](../../../assets/images/gisogd/figure-136.jpg)
  <figcaption>Рисунок 136 — Вкладка «Приложения» в карточке «Публичный сервитут».</figcaption>
</figure>

Для добавления приложения нажать кнопку загрузки файла и выбрать файл на компьютере. После загрузки выбрать файл в списке, чтобы просмотреть его в области предварительного просмотра. Для просмотра файла в отдельном режиме использовать кнопку разворачивания области просмотра.

После заполнения сведений нажать «Сохранить». Для выхода из карточки без сохранения нажать «Закрыть».
