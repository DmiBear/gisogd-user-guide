# Государственная информационная система обеспечения градостроительной деятельности

<div class="gisogd-home" markdown>

<section class="gisogd-home__lead" markdown>

<span class="gisogd-eyebrow">ГИСОГД</span>

Государственная информационная система обеспечения градостроительной деятельности объединяет градостроительные сведения, документы и пространственные данные в единой цифровой среде. Система помогает органам власти и местного самоуправления вести реестры, работать с цифровой картой, предоставлять услуги и переводить межведомственное взаимодействие в электронный вид.

</section>
