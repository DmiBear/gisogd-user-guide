# Руководство пользователя по системе "Государственная информационная система обеспечения градостроительной деятельности"

<div class="gisogd-home" markdown>

<div class="gisogd-home__description" markdown>

ГИСОГД предназначена для сбора, учёта, хранения и размещения градостроительных сведений, документов и материалов. Система используется органами исполнительной власти и местного самоуправления при ведении реестров и предоставлении государственных и муниципальных услуг.

В руководстве описаны вход в систему, навигация, работа с табличными формами и карточками, регистрация заявок, размещение документов, операции с картой и ведение 18 разделов ГИСОГД.
