# О руководстве

Руководство содержит инструкции по работе с платформой ГИСОГД: подготовке к работе, выполнению основных операций, работе с картой, регистрации заявок, размещению документов и ведению реестров ГИСОГД.

Содержание разделено на тематические страницы, связанные общей навигацией и поиском по руководству.

## Программа обучения

В состав сайта также включена программа обучения работе в ГИСОГД: тематический план вебинаров, практические работы, учебные материалы и рекомендации по контролю знаний.
