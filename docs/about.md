# О руководстве

Настоящее руководство предназначено для пользователей Государственной информационной системы обеспечения градостроительной деятельности (далее — Система).

В руководстве описаны подготовка к работе, основные элементы интерфейса, регистрация заявок, размещение документов, ведение реестров и операции с картой. Текст дополняется рисунками, на которых показаны поля, вкладки и команды, используемые при выполнении действий.

Материалы расположены по разделам: от входа в Систему и общих операций до работы с отдельными видами документов. Руководством можно пользоваться последовательно или как справочником при выполнении конкретной задачи. Для перехода к нужной инструкции предусмотрены меню разделов, содержание страницы и поиск.

## Применимость материалов { #applicability }

На сайте сохранены инструкции и рисунки исходного руководства пользователя. Номер сборки, к которой относятся эти снимки, в опубликованных материалах не указан. Если интерфейс вашей системы отличается, уточните версию и доступные команды у администратора.
