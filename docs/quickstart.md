# Размещение документа по заявке

В разделе приведена последовательность размещения документа при наличии зарегистрированной **заявки на размещение документа ГИСОГД**. Порядок включает работу с журналом, записью реестра и карточкой документа.

## Перед началом

Войдите в систему. Подготовьте сведения о документе и необходимые файлы. Определите, к какому [разделу ГИСОГД](gisogd/overview.md) относится документ. Для учебной работы используйте согласованные с преподавателем данные и среду.

Если нужный раздел или команда недоступны, уточните доступ у администратора. Не создавайте повторную заявку, если она уже зарегистрирована.

## 1. Найдите заявку на размещение

Откройте **«Журнал поступивших заявок»** и найдите нужную заявку. При необходимости используйте фильтрацию. Откройте карточку и проверьте, что выбрана заявка, с которой должен быть связан документ.

Порядок регистрации и открытия карточки описан в [«Регистрации заявок»](gisogd/requests.md). Если заявка ещё не зарегистрирована, сначала выполните этот этап.

**Результат:** нужная заявка есть в журнале; известны её номер и дата.

## 2. Создайте запись в нужном реестре

Перейдите в соответствующий реестр через [перечень разделов ГИСОГД](gisogd/overview.md).

Добавьте запись, заполните необходимые сведения и сохраните её. Состав полей зависит от выбранного реестра. Общий порядок приведён в [«Создании записи в реестре раздела»](gisogd/document-placement.md#531).

**Результат:** создана и сохранена запись реестра, к которой будет относиться документ.

## 3. Добавьте документ и файлы

В карточке записи откройте вкладку **«Документы ГИСОГД»** и добавьте документ. Заполните сведения о документе, приложите файлы и сохраните карточку.

Состав полей и вкладок описан в [«Размещении документа во вкладке „Документы ГИСОГД“»](gisogd/document-placement.md#532), работа с файлами — в [«Приложенных файлах»](operations/records.md#451).

**Результат:** документ отображается во вкладке «Документы ГИСОГД» записи реестра.

## 4. Свяжите документ с заявкой

В сохранённой карточке **«Документы ГИСОГД»** выберите заявку на размещение по номеру и дате из выпадающего списка. Сохраните карточку документа.

Откройте заявку и проверьте доступность выбора созданного документа. Для просмотра заявки из карточки документа используйте ссылку **«Посмотреть заявку»**. Эти действия показаны в [инструкции по связыванию документа с заявкой](gisogd/document-placement.md#533).

**Результат:** в документе выбрана нужная заявка, а созданный документ доступен для выбора в заявке.

## Проверьте результат

- Запись находится в нужном реестре.
- Документ виден во вкладке «Документы ГИСОГД» этой записи.
- Необходимые файлы приложены к документу.
- В карточке документа указана правильная заявка на размещение.

Этот порядок не описывает автоматическую смену статуса заявки или выдачу разрешения. Для разрешительных документов используйте [соответствующие инструкции](gisogd/registries/section-13/permits.md).

Если на одном из этапов возникла трудность, откройте [памятку по проверке действий](help.md). Для закрепления материала подойдёт практическая работа **ПР-09** в [программе обучения](training/practice.md#7).
