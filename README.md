# Государственная информационная система обеспечения градостроительной деятельности. Руководство пользователя ГИСОГД. Docs-as-Code проект.

Проект технической документации для платформы ГИСОГД — государственной информационной системы обеспечения градостроительной деятельности.

Репозиторий демонстрирует применение подхода **Docs-as-Code** для разработки и сопровождения пользовательской документации: материалы хранятся в Markdown, собираются с помощью MkDocs, версионируются в Git и публикуются как статический документационный сайт.

## Сайт документации

**[Открыть руководство пользователя ГИСОГД](https://gisogd-user-guide.polakov1245.workers.dev/)**

## О проекте

В рамках проекта большое пользовательское руководство было переработано из традиционного документного формата в структуру документационного сайта.

Основные задачи:

- декомпозиция большого руководства на тематические страницы;
- проектирование структуры и навигации;
- перенос материалов в Markdown;
- организация связей между разделами;
- работа с иллюстрациями;
- подготовка пользовательских инструкций;
- разработка связанной программы обучения;
- настройка автоматизированной сборки и публикации документации.

Документация охватывает основные сценарии работы пользователя с платформой и организована по принципу последовательного перехода от базовых операций к работе с функциональными разделами системы.

## Docs-as-Code

Проект построен по принципам Docs-as-Code.

Используемый стек:

`Markdown` · `MkDocs` · `Material for MkDocs` · `Git` · `GitHub` · `GitHub Actions`

Общий процесс работы с документацией:

```text
Markdown
   ↓
MkDocs
   ↓
проверка документации
   ↓
Git
   ↓
CI/CD
   ↓
публикация сайта
```

Перед публикацией документация проверяется строгой сборкой:

```bash
mkdocs build --strict
```

## Структура проекта

Исходные материалы разделены на несколько логических групп:

```text
docs/
├── пользовательская документация
├── описание функциональных разделов
├── программа обучения
└── графические материалы
```

Навигация документационного сайта задаётся в `mkdocs.yml`.

## Программа обучения

В проект входит связанная с руководством пользователя программа обучения.

Материалы построены таким образом, чтобы пользователь последовательно переходил от знакомства с системой к выполнению практических операций.

Программа включает:

- тематические учебные модули;
- практические задания;
- ссылки на соответствующие разделы руководства;
- контроль освоения материала.

Руководство пользователя при этом используется как основная справочная база для обучения.

## Автоматизация публикации

Для проекта настроена автоматическая сборка документационного сайта.

После обновления исходных материалов изменения фиксируются в Git и передаются в систему CI/CD, после чего обновляется опубликованная версия документации.

Это позволяет сопровождать документацию как обычный программный проект и поддерживать единую актуальную версию материалов.
