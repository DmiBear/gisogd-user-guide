# ГИСОГД — руководство пользователя

Руководство по работе с государственной информационной системой обеспечения градостроительной деятельности. В нём описано, как ориентироваться в системе, работать с картой и реестрами, регистрировать заявки и размещать документы.

**[Открыть руководство пользователя ГИСОГД](https://gisogd-user-guide.polakov1245.workers.dev/)**

## О работе

В этой работе я переработал большое пользовательское руководство в сайт документации. Разделил материал на тематические страницы, организовал навигацию и связал общие инструкции с описанием отдельных разделов системы.

Руководство можно изучать последовательно: от первого входа и знакомства с интерфейсом до работы с документами и реестрами. Если нужна конкретная операция, её можно найти через меню или поиск по сайту. Скриншоты помогают сопоставить описание с интерфейсом и найти нужную форму.

К руководству подготовлена программа обучения с практическими заданиями и ссылками на соответствующие инструкции. Она помогает выстроить занятия так, чтобы после знакомства с системой пользователь переходил к самостоятельной работе.

## Программа обучения

Программа рассчитана на последовательное освоение системы и включает план из десяти вебинаров. Сначала рассматриваются вход, навигация и общие операции, затем — карта, заявки, размещение документов и работа с разделами ГИСОГД.

Для закрепления материала подготовлены [практические работы](docs/training/practice.md). В каждой указаны задание и критерий выполнения. Завершает обучение сквозной сценарий: от учебной заявки до размещённого документа с проверкой связей между записями.

Руководство используется как справочник во время занятий и самостоятельной работы. Порядок проверки знаний и рекомендации для проведения обучения описаны в [отдельном разделе](docs/training/assessment.md).

## Работа с документацией

Материалы подготовлены по подходу **Docs-as-Code**. Текст хранится в Markdown, сайт собирается с помощью MkDocs и темы Material for MkDocs, а история изменений ведётся в Git.

Для обновления инструкции достаточно изменить нужную страницу и связанные с ней иллюстрации. Порядок разделов и настройки сайта заданы в [mkdocs.yml](mkdocs.yml). В репозитории также есть настройка сборки и публикации через GitHub Actions.

## Как открыть сайт на своём компьютере

Для локального просмотра нужен установленный Python. Откройте PowerShell в папке проекта и выполните команды по очереди:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m mkdocs serve
```

Первые две команды подготавливают окружение и устанавливают необходимые компоненты. Последняя запускает сайт. Откройте в браузере [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Чтобы остановить сайт, нажмите `Ctrl+C` в окне PowerShell.

Перед публикацией изменений выполните проверку и сборку:

```powershell
.\.venv\Scripts\python.exe -m mkdocs build --strict
```

Готовый сайт появится в папке `_site`. Если при сборке обнаружатся ошибки или предупреждения, их нужно исправить перед публикацией.
