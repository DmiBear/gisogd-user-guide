# Ведение сайта документации

Проект использует MkDocs и тему Material for MkDocs. Исходные страницы находятся в каталоге `docs`, изображения — в `docs/assets/images`.

## Локальный запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
mkdocs serve
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000/`.

## Проверка перед публикацией

```powershell
mkdocs build --strict
```

Строгая сборка завершается ошибкой при проблемах конфигурации, навигации или ссылок, которые MkDocs считает предупреждениями.

## Рабочий цикл

1. Обновите нужную страницу в каталоге `docs`.
2. Добавьте или замените изображения в `docs/assets/images/gisogd`.
3. Запустите `mkdocs serve` и проверьте результат в браузере.
4. Выполните `mkdocs build --strict`.
5. Проверьте изменения через `git status` и `git diff`.
6. Создайте коммит и отправьте его в удалённый репозиторий.

## Публикация

Публикацию на GitHub Pages следует включать только после проверки локальной сборки и содержимого сайта. Конфигурация проекта уже содержит будущий адрес сайта и ссылку на исходный репозиторий.
